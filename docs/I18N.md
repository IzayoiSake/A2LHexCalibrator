# 国际化维护

简体中文 | [English](I18N.en.md)

1. 在 `src/a2l_hex_calibrator/locales/zh_CN.json` 和 `en_US.json` 添加相同文本键，值分别写中文、英文。不要翻译键名。
2. UI 调用 `self.tr("language.menu")`；动态文本使用命名占位符，例如资源中的 `{p0}` 与调用中的 `p0=count`。地址等特殊格式在调用前格式化，防止语言改变字节/数值语义。
3. `TranslationService` 负责资源读取，UI 不直接打开文件；语言状态属于窗口，不是进程全局变量。数值、地址、变量名、枚举和原始诊断不自动翻译。
4. `.exe` 内置两种语言。旁边的 `locales/zh_CN.json`、`locales/en_US.json` 可覆盖已知文本；仅接受非空字符串且占位符签名一致的值。语法损坏、缺失文件或无效条目回退内置文本。编辑后重启。
5. 语言选择与快捷键共同保存到 `%APPDATA%/A2LHexEditor/shortcuts.json`；旧文件无需迁移。界面切换保留会话、修改和撤销记录，但不在后台任务/弹窗运行期间切换。
6. 新增语言需要增加资源，并显式更新 `LANGUAGES` 与菜单标签；新增文本无需改布局算法。运行完整测试，尤其是资源键/占位符、英文键盘编辑、切换后的筛选及按钮可见性。
7. `pyproject.toml` 将 JSON 纳入 Python 包，`build.ps1` 用 `--collect-data a2l_hex_calibrator` 纳入 EXE。发布前用不带外置资源的 EXE 做中英文冒烟测试。

Windows 原生对话框系统按钮遵循系统语言。底层解析器诊断保留原文，A2L 的描述与枚举由文件提供。
